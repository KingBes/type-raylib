## 环境注意（重要）
- Git Bash 下 `/usr/bin/link`（coreutils）会抢占 MSVC 的 `link.exe`，导致 tpc 链接失败（`link: extra operand`）。修复：编译前把 MSVC bin 提到 PATH 最前，例如
  `export PATH="/c/Program Files/Microsoft Visual Studio/2022/Community/VC/Tools/MSVC/14.44.35207/bin/Hostx64/x64:$PATH"`。
- `tpc` 位于 `C:\env\swoole_compiler\tpc.exe`（v0.4.3）。func_decl.h 由编译器每次从 stub.php 重新生成，无需手维护。
